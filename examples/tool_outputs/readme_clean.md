# fastcsv

A small library for reading CSV files quickly.

## Installation

Run `pip install fastcsv` and then import it with `import fastcsv`. Create a virtual environment first if you want to keep your system Python clean.

## Usage

Call `fastcsv.read("data.csv")` to get a list of rows. Set `delimiter=";"` for European files. Click the "Download" button on the releases page to get prebuilt wheels.
